PDF Insight

PDF Insight is an AI-powered document question-answering system that allows users to upload PDFs and ask questions based on the document content.

Features:
Upload PDF files
Ask questions from documents
Semantic search with embeddings
AI-generated answers with source references
Technologies
Python
FastAPI
LangChain
Sentence Transformers
Groq API
Installation
pip install -r requirements.txt
Set API Key

Linux/Mac:
export GROQ_API_KEY=your_api_key
Windows:
set GROQ_API_KEY=your_api_key
Run Project: 
uvicorn main:app --reload
